---

## 📋 Overview

LifeBoard is a multi-user web application that allows users to manage their personal productivity through three interconnected entities: **Goals**, **Habits** and **Tasks**. The system generates automatic insights based on behavioral patterns and calculates a daily **Life Score** using a MySQL Stored Procedure.

---

## ✨ Features

- 🔐 **Authentication** — Register and login with JWT Bearer tokens and BCrypt password hashing
- 🎯 **Goals** — CRUD with progress tracking, categories and due dates
- 🔁 **Habits** — Daily/weekly habits with streak tracking and daily check-in
- ✅ **Tasks** — Task management with priority levels, status changes and overdue detection
- 📊 **Dashboard** — Visual metrics with bar charts, donut chart and line chart (Recharts)
- 🧠 **Insights** — Automatic behavioral insights generated by business logic
- 🏆 **Life Score** — Daily score (0-100) calculated by a MySQL Stored Procedure
- 📱 **Responsive** — Fully functional on desktop and tablet

## 🗄️ Database

6 tables normalized to 3NF:

| Table | Description |
|---|---|
| `users` | Registered users |
| `goals` | Personal goals with progress |
| `habits` | Daily/weekly habits |
| `habit_logs` | Daily habit completion history |
| `tasks` | Tasks linked to goals |
| `life_scores` | Daily life score history |

**Stored Procedure:** `sp_calculate_life_score` calculates the daily score:
```
Score = (habits_pct × 0.40) + (tasks_pct × 0.35) + (goals_pct × 0.25)
```

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- .NET 8 SDK
- MySQL 8.0

### 1 — Clone the repository
```bash
git clone https://github.com/codelearner03/lifeboard.git
cd lifeboard
```

### 2 — Database setup
```bash
# Open MySQL Workbench or any MySQL client
# Run the script:
source database/lifeboard_db.sql
```

### 3 — Backend setup
```bash
cd backend/LifeBoard.API/LifeBoard.API

# Update appsettings.json with your MySQL credentials
# ConnectionStrings.DefaultConnection

dotnet restore
dotnet run
```

API runs on: `https://localhost:7201`
Swagger UI: `https://localhost:7201/swagger`

### 4 — Frontend setup
```bash
cd frontend/lifeboard-app

npm install
npm run dev
```

App runs on: `http://localhost:5173`

## 🔒 Security

- Passwords hashed with **BCrypt** (factor 10)
- **JWT Bearer** tokens with 24h expiration
- All private routes require valid token
- CORS configured for specific origins only
- No credentials hardcoded — environment variables for production

---

## 🎯 Design Decisions

- **No ML for insights** — insights generated with SQL queries and business logic rules, keeping the stack simple and maintainable
- **Stored Procedure for Life Score** — demonstrates database-level business logic
- **Desktop + Tablet responsive** — mobile support planned as future improvement
- **Custom JWT Auth** — implemented from scratch to demonstrate understanding of authentication fundamentals
